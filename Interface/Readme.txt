В данной директории хранится проект графического интерфейса web-приложения.

В проекте используются Javascript, HTML, CSS, React.js, rabbitmq. 

В проекте есть следующие зависимости:
React и связанные библиотеки:
react: основной фреймворк для создания пользовательского интерфейса
react-dom: библиотека для работы с DOM-элементами в React
react-redux: библиотека для интеграции React с Redux
react-bootstrap: библиотека для создания интерфейса с помощью Bootstrap в React
Redux и связанные библиотеки:
redux: основной фреймворк для управления состоянием приложения
@reduxjs/toolkit: библиотека для создания и управления Redux--store
redux-actions: библиотека для создания и управления действиями в Redux
Линтинг:
eslint: линтер для проверки кода на ошибки и соответствие стандартам
eslint-config-airbnb: конфигурационный файл для eslint с настройками от Airbnb
Сервер:
express: фреймворк для создания сервера
amqplib: библиотека для работы с RabbitMQ
Дополнительные библиотеки:
plotly.js: библиотека для создания интерактивных графиков
dockview: библиотека для создания оконного интерфейса
buffer: библиотека для работы с буферами данных
process: библиотека для работы с процессами
stream-browserify: библиотека для работы с потоками данных в браузере
uuid: библиотека для генерации уникальных идентификаторов

Для установки необходимо (все действия выполнять как администратор):
1) установить npm (или npm-windows для windows), npm - это менеджер версий node.js;
2) установить node.js;
3) установить rabbitMQ;
4) сделать pull этой ветки;
5) выполнить команду в терминале/powershell npm install (это установит все необходимые зависимости для проекта)
6) выполнить команду в треминаое/powershell npm run build (это соберет реакт приложение)

Для запуска необходимо
1) локально запустить сервер выполнив в терминале/powershell команду npm run server     
2) перейти по http://localhost:5000       
3*) При желании можно включить эмулятор отправки данных в rabbitMQ, для этого запустите в отдельном терминале/powershell npm run producer
Этот эмулятор будет посылать 10 точек в секунду графика ретинола в очередь с окончанием _reqv, название которой придет в main_set.    

Скрипты запускаются комбинацией npm run СКРИПТОВОЕ_ИМЯ.

имя: start
Запускает одновременно клиентскую и серверную части приложения. Использует пакет concurrently для параллельного выполнения команд. Полезно для разработки, чтобы сразу видеть изменения как на фронтенде, так и на бекенде.
"start": "concurrently "npm run client" "npm run server""

имя: build
Создаёт оптимизированную сборку вашего React-приложения для продакшена. Использует craco (Create React App Configuration Override), чтобы управлять конфигурацией CRA без необходимости извлекать её.
"build": "craco build"

имя: test
Запускает тесты вашего приложения с использованием craco. Позволяет настраивать конфигурацию тестирования через craco.
"test": "craco test"

имя: eject
Извлекает скрытую конфигурацию Create React App, позволяя вам напрямую изменять конфигурационные файлы. Внимание: после выполнения этой команды возврат к скрытой конфигурации невозможен.
"eject": "react-scripts eject"

имя: lint
Запускает ESLint для проверки кода в папке src/ и автоматически исправляет ошибки форматирования, если это возможно. Полезно для поддержания чистоты и консистентности кода.
"lint": "eslint src/ --fix"

имя: producer
Запускает скрипт producer.js, расположенный в папке src/testing. Этот скрипт может быть предназначен для тестирования или генерации данных.
"producer": "node ./src/testing/producer.js"

имя: client
Запускает клиентскую часть вашего React-приложения в режиме разработки. Использует craco для возможности настройки конфигурации.
"client": "craco start"

имя: server
Запускает серверную часть вашего приложения с использованием nodemon, который автоматически перезапускает сервер при изменении файлов. Полезно для разработки серверной логики.
"server": "nodemon ./src/server/server.js"
Чтобы запустить скрипт, используйте команду npm run <script-name>, где <script-name> - имя скрипта, например, npm run start.
Для работы в первый раз используйте npm run start-dev так приложение сначала соберется, а потом запустится сервер, доступ к реакт приложению будет по адресу http://localhost:3001  (ОБРАТИТЕ ВНИМАНИЕ НА 1 в конце).
После первой сборки, можно использовать npm start-server, так будет быстрее так как пропуститься этап сборки.
